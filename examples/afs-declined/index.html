AFS Declined Payment Example

About this example

This example demonstrates how to handle a payment declined by AFS (Anti-Fraud System).

There are two possible flows when AFS blocks a payment:

Flow 1: show_errors action

When AFS blocks immediately, the SDK returns a show_errors action with error code 1092 (declinedByAfsAfterInvoiceCreated).

Flow 2: check_status action

When AFS blocks after invoice creation, the SDK returns a check_status action. The status will have titleClass: "cancel", which the SDK now correctly maps to a declined state (not "processing").

How to trigger AFS decline:

  • Use sandbox mode with a test card configured to trigger AFS rejection
  • Or configure AFS rules in Xsolla Publisher Account to block specific patterns
