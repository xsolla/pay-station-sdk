AFS Declined Payment Example

About this example

This example demonstrates how to handle a card payment declined by AFS (Anti-Fraud System). There are two flows:

Flow 1: show_errors action

When AFS blocks immediately, the SDK returns a show_errors action with error code 1092 (declinedByAfsAfterInvoiceCreated).

Flow 2: check_status action

When AFS blocks after invoice creation, the payment is auto-refunded and the SDK returns a check_status action. The status component then resolves to a canceled state once getStatus() reports the terminal verdict — it no longer hangs on "processing".
